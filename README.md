Quiz Application -

A modern and responsive Quiz Application built using Spring Boot, Thymeleaf, HTML, CSS, and Bootstrap.
This project allows users to register, login, attempt quizzes, and view their final scores with a clean UI experience.

📌 Features
🔐 User Authentication (Login & Signup)
🧠 Multiple Quiz Categories
✅ MCQ Based Quiz System
📊 Instant Quiz Result & Score Display
🎨 Responsive and Modern UI
🚪 Logout Functionality
🗂 Organized MVC Architecture
💾 Backend Integration using Spring Boot
